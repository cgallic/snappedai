OpenClaw Agent Treasury — PRD v0

Problem

Agents have recurring operating costs (API, compute, infra) and no native capital layer. Manual top-ups + no runway visibility.

Vision

Every agent has a treasury, policy, and ops wallet; gains offset uptime costs.

Core Outcome

Agents sustain part (or all) of operating spend with auditable, policy-governed treasury logic.

Users

  • Agent builders running 1–100+ agents
  • DeFi-native operators
  • Multi-agent startups with monthly infra burn

Success Metrics

  • Self-Funding Ratio = treasury gains / agent spend
  • Runway days
  • % agents with policy enabled
  • % spend covered (30d)

V1 Scope

  • Agent Wallet Model: treasury + ops
  • Policy Engine: caps, drawdown, drift, reserve floor
  • Sweep Scheduler: treasury → ops
  • Spend Ledger integration
  • Flight Recorder for every decision
  • Dashboard: balance, PnL, burn, runway, self-funding ratio

Out of Scope (V1)

  • HFT/autonomous high-frequency trading
  • Cross-chain complexity
  • Full compliance routing
