On-Call OS — Day 1 Build Checklist

Gemini Live Agent Challenge • Scope: emotional demo + auditability layer

0) Scope Lock (30 min)

  • One incident only: latency spike + 5xx surge
  • 3 agents only: Historian / Impact Assessor / Triage Lead
  • One output: incident summary + top 3 hypotheses + next 3 actions

1) Repo + Skeleton

  • Create repo: oncall-os
  • Folders: apps/web, apps/api, agents/, docs/
  • README with hackathon goal + setup stub

2) GCP Baseline

  • Create GCP project + enable Gemini/Vertex, Cloud Run, Logging
  • Deploy hello-world API to Cloud Run
  • Capture proof screenshot: service URL + logs

3) Gemini Live Wiring

  • Add /live/session endpoint
  • Mic stream input (text fallback acceptable Day 1)
  • Stream assistant response
  • Support interruption/cancel

4) Agent Orchestration Stub

  • Add /incident/analyze
  • Run parallel roles: Historian, Impact, Triage
  • Merge to structured JSON response

5) Flight Recorder v0

  • Log each step: timestamp, role, input summary, output summary, confidence
  • Render timeline in demo UI

6) UI Shell

  • Left: live transcript + mic status
  • Right: hypotheses + recommended actions cards
  • Bottom: Flight Recorder trace timeline

7) End-of-Day Success Test

  • Input: “Latency up 4x, 5xx at 12%, started 20 min ago after deploy.”
  • Output: 3 hypotheses, 3 actions, visible multi-agent trace, live URL on GCP

8) Required Artifacts (Day 1)

  • Public repo pushed
  • App screenshot
  • GCP proof screenshot
  • Short status update posted
